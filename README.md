# Enterprise AI Resume Analyzer

An enterprise-level AI-powered resume analysis platform for HR and recruiters.

## Planned Technologies

- Python
- FastAPI
- LangChain
- LangGraph
- RAG
- Vector Database
- LLMs
- Angular
- Docker
- AWS

## Project Goal

The system will analyze resumes against job descriptions and provide
evidence-based candidate insights using Generative AI.
